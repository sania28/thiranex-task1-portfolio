## ✨ About The Project

This is my **Full Stack Developer Portfolio Website**, developed to present my professional profile, technical capabilities, projects, education, experience, and contact information in a modern and responsive interface.

The website combines a user-friendly frontend with a **Node.js + Express backend** and **MongoDB database integration**, allowing dynamic portfolio data and contact submissions to be managed through the backend.

This project was developed as part of my **Full Stack Development Internship — Task 1 at Thiranex**.

The project also demonstrates practical experience with:

* Frontend development
* Backend development
* REST API integration
* Database connectivity
* Environment-based configuration
* Git & GitHub workflow
* Cloud deployment
* Production configuration

# 🚀 Getting Started

## Prerequisites

Before running the project locally, make sure you have:

* **Node.js 18+**
* **npm**
* **MongoDB** or a **MongoDB Atlas** account
* Git
* A code editor such as VS Code

---

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/sania28/thiranex-task1-portfolio.git
```

---

## 2️⃣ Navigate to the Project

```bash
cd thiranex-task1-portfolio
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Configure Environment Variables

Create a `.env` file in the project root.

```env
MONGODB_URI=your_mongodb_connection_string
PORT=5000
NODE_ENV=development
```

If email notifications are configured:

```env
EMAIL_USER=your_email
EMAIL_PASS=your_app_password
EMAIL_TO=your_destination_email
```

> Never commit your `.env` file to GitHub.

---

## 5️⃣ Seed the Database

If the project includes the seed script:

```bash
npm run seed
```

This can be used to populate the database with initial project data.

---

## 6️⃣ Start the Application

```bash
npm run dev
```

Or:

```bash
node server.js
```

Open:

```text
http://localhost:5000
```

# 🔐 Security & Environment Variables

Sensitive information is intentionally kept outside the GitHub repository.

The following should be configured through environment variables:

```text
MONGODB_URI
EMAIL_USER
EMAIL_PASS
EMAIL_TO
NODE_ENV
```

The `.env` file should **never be committed** to the repository.

Example:

```env
MONGODB_URI=your_mongodb_connection_string
```

The `.env.example` file can be used as a template for local configuration.

---

# 📧 Contact Form & Email Notifications

The portfolio includes a contact form that can be connected to email notifications.

For Gmail-based notifications, an **App Password** should be used instead of the regular Gmail password.

Required configuration:

```env
EMAIL_USER=your_gmail_address
EMAIL_PASS=your_gmail_app_password
EMAIL_TO=destination_email
```

### Important

* Enable 2-Step Verification on the Gmail account.
* Generate an App Password.
* Never expose the App Password in source code.
* Never commit `.env` to GitHub.
